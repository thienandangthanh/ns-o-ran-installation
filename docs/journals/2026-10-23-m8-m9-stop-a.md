## 2. Lessons
- **Count Verify fields, not checks.** "103/103" hid three missing V-items, because the checks had been written to C1 and not to the phase's Verify list. A comparator script that reads the Verify list off `verdict.json` caught the gap at once. Run one for every phase before calling it green.
- **Fixture-first changes protect a green rung.** Every shared-tool change was regenerated against the last green evidence and compared byte for byte. That kept R0 valid without re-running it.
- **A deferred fix can be the wrong fix.** The P2 deferral pointed the wrong way for V4. Re-derive deferred items from the code at the pins before implementing them.
- **Timing noted on the card must be checked against `date`.** Two resume-card timestamps were written ahead of the real clock and corrected afterwards.
