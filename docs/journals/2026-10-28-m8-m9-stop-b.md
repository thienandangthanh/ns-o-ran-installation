## 2. Lessons

- Moving a foreground step into the background, so the runner can supervise it, changes signal semantics. The TERM trap now fires during `sleep` or `wait`, and the step must be stopped explicitly. The reviewer caught this; Codex had reviewed the code before the change.
- A monitor's "alive" record needs a timestamp. A counter alone cannot tell a run that was watched to the end from one whose watcher died early.
- Warm dev runs understate install times. The budget must use the gate's own cold-path caps.
