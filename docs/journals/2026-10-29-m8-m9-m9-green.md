# 2026-10-29: M9 green on the fourth attempt

## What happened
M9 ran unattended from `fresh-install` and passed: 14 of 14 steps, R3′ C1 equal to its reference, minimum host free 59 GB, watchdog alive (`plans/261023-0009-GH-1-m8-m9-paced-rungs-and-m9/evidence/m9/20261028T165825Z/verdict.json`). Wall time was 3 h 31 min of a 5 h 37 min budget.

## How we got there
- **Attempt 1 (harness defect).** A torn heartbeat read cancelled the run in m2. Guided fix F′: an atomic heartbeat write.
- **Attempt 2 (environment).** Claude Code's low-memory reaper killed the runner's background shell in m3 while a browser was open next to a 16 GB VM. The user rebooted the host, set the reaper variable, and ruled that the runner runs as a `systemd-run --user --wait` unit with a memory gate. Every leaked overlay was then deleted under the standing leaked-overlay ruling.
- **Attempt 3 (RIC platform).** m6 failed: the agent sent 12 E2 Setup Requests and got no response. The live VM showed ESTABLISHED RMR sessions with about 126 KB unread in e2mgr's and submgr's receive queues: their route-table readers had stopped, so e2mgr had no route for the response. The AddE2T 400s were a red herring, since the green m5 boot had them too. Two things hid the fault from the preconditions: e2mgr marks a node CONNECTED before it sends the response, and rtmgr logs success for pushes that never land.
- **Guided fix F″.** Detect a stuck reader by its rx_queue on port 4561, then replace e2mgr and submgr and restart rtmgr last. It was validated on the wedged VM before the revert: STUCK, then one refresh of 111 s, then READY. In attempt 4 it fired once, in m1, right after the RIC install, so the wedge is not only a reboot effect.

## Lessons
- Validate a guided fix on the broken state when you still have it; the live capture changed the fix from "restart rtmgr" to "replace the readers".
- Judge readiness on the receiver, not on the sender's log or the manager's status.
- A long unattended run on a desktop host needs process isolation from the agent session and a memory budget, not only a disk budget.
