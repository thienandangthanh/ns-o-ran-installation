  • decision"RC_OK" in gates means a clean decode: asn1c code RC_OK and consumed == input length and, for headers, the decoded TimeStamp is 8 octets. Reason (selftest finding): a SIZE(4) decoder fed an 8-byte-timestamp header with no optional fields returns RC_OK after consuming 5 of 9 octets, giving a wrong timestamp. A bare return-code check would pass a broken decode. This is stricter than the plan text, never looser.
