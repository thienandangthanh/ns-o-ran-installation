P0: harness generalization, RC wire decoder, disk baseline

  • decisionGate id = ^gate-([a-z]+[0-9]+) through one gate_id helper in vm-common.sh, used by vm-exec.sh and self-tested in lint.sh (m5 r0 s1 q7).
  • decisionProtected snapshots live in one list, VM_NEVER_DELETE=(fresh-install f7-rerun-green r3-green); vm-snapshot.sh delete refuses them before any virsh call and check-protected exposes the rule.
  • decisionThe disk watchdog keeps the minimum free space seen in min-host-free-gb.txt, so the M9 verdict reports minHostFreeGb from the watchdog, not from point samples. On a trip it kills the runner's foreground child first: bash defers a TERM trap until the foreground child exits, and a stopped VM unit never writes exit_code, so vm-exec.sh would otherwise wait ~20 min for ssh.
  • decisionrun-to-m9.sh step names: i0 (decoder + rc install), r0, r1, i2 (TS xApp + stub QP), r2, i3 (stub down + QP fork), r3. Install steps are gates of their own so each has a verdict and evidence. The runner writes evidence/m9/<ts>/verdict.json on every exit path.
  • decisionRC decoder tools/rc-decode/: asn1c mouse07410@584d86e (−O0) over rc@a2282ee e2sm-common.asn + e2sm-rc-2.0.asn, APER, XER out. "ok" = RC_OK and every octet consumed (the M0–M7 decoder rule). It never calls asn_check_constraints (loops on RANParameter-bearing PDUs).
  • decisionFixture: 30 RICcontrolRequest PDUs from the probe pcap (sha256 e57c5713…), tshark 4.7.4 fields e2ap.RICcontrolHeader/e2ap.RICcontrolMessage. Every header decodes 22/22 octets with style 3, action 1, UEID = gNB-UEID; every message 36/36 octets with the NR CGI as valueOctS of RAN parameter 4 nested under parameters 1/2/3. A synthesized ControlOutcome Format 1 with an empty ranP-List encodes to 0000 and round-trips.
  • decisionThe probe's NR CGI octet string is 9 bytes (00 00F110 0000000003). That is the APER encoding of the E2SM common NR-CGI SEQUENCE (extension/preamble octet, 3-byte PLMN, 36-bit cell identity padded to 5 octets) carried as valueOctS. The agent (P1) decodes it as NR-CGI; the gate compares decoded bytes.
  • tradeoffThe watchdog test (V3) shut the VM down gracefully; it was started again at the same snapshot (f7-rerun-green), so no state changed.
