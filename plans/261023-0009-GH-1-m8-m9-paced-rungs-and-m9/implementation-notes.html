  • decisionThe probe's NR CGI octet string is 9 bytes (00 00F110 0000000003). It is raw octets, not APER: rc a2282ee builds it as hex.DecodeString("00"+PLMN+TargetCellID) (control/rcE2SmRc.go:101-102; the APER NR-CGI encoder in e2sm/wrapper.c is commented out). The agent parses length 9, byte 0 = 00, bytes 1–3 = PLMN, bytes 4–8 = the 5-byte cell key; with the N5 key %08X%02X the target cell id is byte 8. An APER NR-CGI decode would drop that byte (it sits in NCI's pad nibble, verifier-1723 #12) and give NCI 0. (Corrected 02:02 KST after kongming's P0 exit review; an earlier note here said APER.)
